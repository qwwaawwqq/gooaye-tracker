# Gooaye 股癌 · 預測追蹤站

私人追蹤站，整理 Gooaye 股癌 podcast (謝孟恭) 各集點名的個股、主軸論述，與實際走勢驗證。

📊 **內建內容（截至 2026/05/09）：**
- EP651-EP660 共 10 集深度摘要
- 23 項預測驗證 (HIT 17 / PARTIAL 3 / MISS 2 / PENDING 1)
- 20 檔個股 scorecard（台股 + 美股）
- 73% 整體命中率回測

🔄 **即時 RSS 偵測：** 每次開啟自動拉 SoundOn RSS，自動偵測新集出爐並標 NEW。

## 開發

純靜態 HTML，無需 build。直接打開 `index.html` 即可。

## 部署

GitHub Pages：repo Settings → Pages → Deploy from a branch → main / (root)。
